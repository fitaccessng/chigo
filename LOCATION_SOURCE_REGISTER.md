## Source Handling Notes

- Coordinate reference system for the project importers is WGS84 / EPSG:4326; verify source metadata for every file before ingestion.
- Public OSM API, tile, and Nominatim policies are service-use rules and must not be conflated with ODbL dataset terms. No bulk public geocoding was performed.
- No source is declared FCT-complete. No geographic data was downloaded or written during this audit.
